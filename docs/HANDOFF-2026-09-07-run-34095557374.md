## Decided, not deferred

These were deferred three times and scheduled zero times, which is a decision not
to do them recorded as a decision to do them later. That third state is what
costs, so each one below is now either SCHEDULED with an ordering and a
precondition, or ACCEPTED with the trigger that would reopen it. "Recorded in the
handoff" is not a state.

Each also records **cost already paid** rather than work remaining.

**1. Reachability sweep - SCHEDULED, first work of the next session, before any
dispatch work and before item 2.** Precondition is a fresh session, not spare
time: it deletes graph databases and the live graph can sit inside the namespace
it sweeps. It is first because it crossed the build-it threshold two fixes ago -
two independent instances is the evidence that would justify an abstraction
anywhere else, and this has three.

**2. Footprint bounding - SCHEDULED, after item 1.** It is the larger prize and
the larger design change, and it is gated on graph currency at an edit boundary.
Do not start it while that number is 34%.

**3. `core.hooksPath` across 56 worktrees - ACCEPTED, not doing it.** The
relative-path change silently disables construction hooks on 26 worktrees, and
the alternative broke `git status` everywhere today. What is accepted: every
branch runs `linear/har-81-diagnostics`'s hook and carries false confidence about
its own gate. **Trigger to reopen: the second time a worktree discovers its gate
was inert.** The first time was today.

### 1. Reachability sweep over the graph namespaces

Would subsume revision retention, enrichment refusal, and the in-flight orphan.
**Three partial implementations already shipped** - `_prune_superseded_revisions`,
the `_observe_enrichment` cleanup, and the scheduling-time sweep - each carrying
its own liveness guard that must agree with the other two. The argument about
roots and what must not be deleted was re-derived three times, and the
"do not delete the live graph" guard written twice.

**The trap:** `certify_lsp_candidate` returns the candidate path unchanged
(`indexer.py:1773`) and the coordinator publishes exactly that, so the live
`graph_path` can point **into** `enrichments/`. A path rule or an unconditional
sweep deletes the live graph. That is why it must be reachability.

### 2. Bound the dependency footprint by the graph's import closure

The measured cause of the step inflation. Today every footprint claims the whole
workspace, so every edit invalidates every proven obligation. GT holds the one
artifact that could narrow it - a test file's transitive imports.
**Gated on graph currency at an edit boundary, currently 34%**, which is itself
gated on the rebuild cadence above.

### 3. `core.hooksPath` across 56 worktrees

`git config core.hooksPath .githooks` (relative) resolves per-worktree and is
cheaper than the per-worktree override. **26 of 56 worktrees have no
`.githooks/pre-commit` and would silently lose all construction hooks.**
All 56 currently run whatever `linear/har-81-diagnostics` has - every branch
carries false confidence about the gate it thinks it has.

**Do not enable `extensions.worktreeConfig` without moving `core.bare` first:**
doing so made `git status` fail in all 56 worktrees today.

## Method notes that earned their place

- **A check that has never produced its non-default output has not been shown to
  work.** Covers assertions, queries, emitters and gates.
  `scripts/check_census.py` answers it per emitter; 29 are dark over two runs.
- **Uniformity is an instrument signature when nothing predicted it, and
  confirmation when something did.** Test: was the mechanism read before the
  observation, and could the observation have refuted it?
- **A rule whose subject is a noun is a special case; a rule whose subject is a
  relation is a principle.**
- **Do not write the past tense without naming the witness.** "Shipped" needs a
  commit; "verified" needs the output.
- **Before reading an artifact, confirm the artifact is complete.** A directory
  being enumerable is not a download being finished.
- Six wrong-scope reads in one day, all the same shape: the query's scope and the
  conclusion's scope differed, and the empty result was evidence about the query.
