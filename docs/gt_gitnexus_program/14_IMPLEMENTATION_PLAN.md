# Final implementation and verification plan

## Objective

Produce one exact GT candidate on which every required deterministic mechanism
runs, abstains explicitly when inapplicable, and emits enough provenance to
audit what it computed, selected, delivered, and what the model did next. Solve
rate and efficiency remain benchmark results; mechanical completeness is the
precondition for spending on them.

## Implemented repairs

1. Declaration-free supported source receives an identity-only graph file node;
   every semantic consumer excludes that node from symbol authority.
2. Graph database and manifest publication are atomic, locked, recoverable, and
   content-certified.
3. Initial and incremental graph refresh execute synchronously with the timeout
   passed into the real index operation. No abandoned thread or deferred
   escalation can mutate later state.
4. Repository/process context is bounded, action-relevant, uncertainty-aware,
   and admitted through the shared provider-value compiler.
5. Coupled obligations and resolved conventions are advisory compositions of
   certified constituents, never guesses.
6. Observed-execution facts receive a selected, represented, rejected, or
   terminal disposition; rejected facts cannot starve newer evidence.
7. Trial outcomes are typed and mutually exclusive. Provider censors require
   actual transport markers; generic verifier timeout text is not a censor.
8. The paid route is derived from the frozen baseline manifest. Secret values
   remain GitHub secrets. Scheduled benchmark dispatch and secret-valued event
   inputs are forbidden.
9. All required research and release documents are link-checked and audited.

## Required verification before money

1. Focused RED/green witnesses for every repair.
2. Substrate/graph, semantic/state, delivery/control, and release/workflow test
   lanes.
3. Complete Python suite, compilation, workflow parse, diff, and secret scan.
4. Current Go source test/build on Linux with `sqlite_fts5`.
5. Real pinned ONNX asset proof.
6. All 17 actual-agent feature trigger witnesses plus persistent lifecycle.
7. Current replay of all 20 archived receipts, with historical runtime/censor
   limitations reported rather than waived.
8. Final runtime commit, then a two-file prediction/release freeze.
9. Exact pushed-SHA provider-free `READY`, `SMOKE_APPROVED`, and mechanical
   completeness proof.

## Stop gate

Only after all nine checks pass may exactly one paid `repair20-v1` GT-on matrix
run at parallelism 20. The run reports integrity, solves, efficiency, and
intervention causality separately. No repeated smoke loop is part of this plan.
