# GT negative-flip autopsy

No archived baseline-only outcome has confirmed GT causality. Confidence is
high in that limitation because the frozen baseline contains rewards and
resource totals but no baseline action trajectory. A call-1 provider-view
difference proves intervention accounting, not why the final reward changed.

The strongest treatment-side risk mechanisms were repeated return loops,
harness-oriented wording, overbroad root-search blocking, stale graph state,
and repeated rejected observed facts. These have general repairs in the
current candidate. They were not patched with task-ID rules.

Current causal labels are `CONFIRMED: none`, `HIGH: none`, and
`MEDIUM/LOW/UNKNOWN` for raw negative flips depending on treatment-side
evidence. The next matched run must retain both arms' trajectories or use a
mechanism ablation before a GT-caused loss is claimed.
