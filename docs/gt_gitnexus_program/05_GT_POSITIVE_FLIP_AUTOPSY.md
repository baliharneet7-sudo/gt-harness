# GT positive-flip autopsy

The latest archived cohort contains one raw GT-only solve,
`largest-eigenval`. It is a product lead, not a causal claim. The baseline arm
has no action trajectory, so the decisive divergence cannot be reconstructed.

Mechanisms with credible general value are certified nonlocal caller/test/
impact context, change-surface and signature-delta evidence, bounded validation
contradictions, graph-first persistent state, and task-semantic checks on
graph-non-applicable workspaces. They are implemented and observable. None is
credited with a causal solve until a matched trajectory or ablation exists.
