# Direct GitNexus comparison plan

Run bare Mini-SWE, GitNexus, GroundTruth, and—if compatible—GitNexus repository
intelligence plus GT's certification/intervention layer. Require equal task and
repository SHAs, model route, sampling, prompts, tool contract, budgets,
evaluator, trial count, and failure accounting.

Primary metric is solved tasks. Secondary metrics are cost per solve, provider
calls, uncached input, total tokens, searches, reads, tests, wall time, and
attributable negative flips. GT outperforms only through a defensible Pareto
improvement.
